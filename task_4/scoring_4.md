Используется единая логика оценки по каждому из критериев:

0 - отсутствует или полностью некорректно
1 - выражено слабо, есть существенные ошибки
2 - частично корректно, есть методологические неточности
3 - в целом корректно, незначительные замечания
4 - полностью корректно и методологически обоснованно

Для каждого из критериев задается свой весовой коэффициент, отражающий значимость критерия в модели скоринга.

## Формула итогового балла

1. Для каждого критерия выставляется оценка от 0 до 4.
2. Рассчитывается взвешенный балл критерия:

`Взвешенный_балл_критерия = Оценка_критерия * Вес_критерия`

3. Суммируются взвешенные баллы по обязательным разделам:

`Сумма_обязательная = Σ(Оценка_i * Вес_i)`

4. Рассчитывается максимальный обязательный балл:

`Максимум_обязательный = 4 * Σ(Вес_i обязательных критериев)`

5. Отдельно считается бонус за "звездочку":

`Бонус_звездочка = Σ(Оценка_j * Вес_j бонусных критериев)`

`Максимум_бонус = 4 * Σ(Вес_j бонусных критериев)`

6. Итоговый процент по обязательной части:

`Итог_% = (Сумма_обязательная / Максимум_обязательный) * 100`

7. Дополнительный бонусный процент:

`Бонус_% = (Бонус_звездочка / Максимум_бонус) * 100`

## Интерпретация результата

- 85–100%: высокий уровень проработки обязательной части
- 70–84%: хороший уровень, есть точечные доработки
- 50–69%: средний уровень, требуются существенные улучшения
- <50%: низкий уровень, работа требует переработки

Рекомендация по учету бонуса:
- Бонусную часть учитывать как повышающий коэффициент к итогу обязательной части, без компенсации провалов по базовым требованиям.
